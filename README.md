# Siphon

A planned terminal installer for AI coding agents. This repository currently contains research notes and a shared Bash color palette; the installer is not implemented yet.

- [Project notes](docs/Notes.md)
- [CLI research](docs/MultiAgent.md)
- [Terminal palette](scripts/theme.sh)

Preview the palette with:

```sh
bash scripts/theme.sh
```

Set `SIPHON_THEME` to `dark`, `light`, or `auto`. Set `NO_COLOR=1` to disable colors. The CLI installation commands in the research notes have not been verified as part of this project.
